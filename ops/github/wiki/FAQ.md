# FAQ

## Wikiが正本ですか

いいえ。Wikiはoutput-onlyの案内です。正本はrepository、Issues、Discussions、Projectに分かれます。

## 1998年の日付は実在の履歴ですか

いいえ。すべてsynthetic fixture metadataです。

## Issueを閉じればFindingが確定しますか

いいえ。Issueは作業と受入条件を管理します。Findingへの昇格はrepository recordと人間レビューが必要です。

## 投票結果や参加者はsnapshotに入りますか

いいえ。snapshotはallowlist済みのstable ID、GitHub ID、URL、title、status、enumだけです。

## Pagesはありますか

ありません。Private repository内のWikiとlocal/offline demoだけを使用します。

> English summary: The Wiki is navigation, fixture dates are synthetic, and no
> participant data or free text enters the GitHub object snapshot.
