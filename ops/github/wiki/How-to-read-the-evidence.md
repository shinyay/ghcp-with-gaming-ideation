# How to read the evidence

1. stable IDを確認する
2. `archive/catalog/assets.yaml`で`demo-safe`と`ai_eligible: true`を確認する
3. catalogに宣言されたlocatorを使う
4. Evidence、Inference、Proposalを別々に書く
5. 単一資産だけで結論を確定しない
6. Conflictを両側のまま保持する
7. Findingへの昇格は人間レビューへ渡す

手順の正本は[`governance/evidence-policy.md`](https://github.com/shinyay/ghcp-with-gaming-ideation/blob/main/governance/evidence-policy.md)です。

> English summary: Cite an eligible DRV and declared locator, separate inference,
> and leave promotion to a human reviewer.
