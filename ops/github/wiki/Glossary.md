## Role Lens

専門職が一般に使うreview観点を、同じtargetへ適用するread-only Custom Agentです。
実在または架空の人物、reviewer、approver、team consensusではありません。
複数Lensの出力は、実際の人間teamへ返すquestionsとriskを準備するために使います。

共通contractは
[`governance/role-lens-contract.md`](https://github.com/shinyay/ghcp-with-gaming-ideation/blob/main/governance/role-lens-contract.md)
です。

> English summary: Stable IDs separate domain records from mutable GitHub
> numbers. A Role Lens is a read-only professional analysis framework, not a
> fictional colleague or approver.
