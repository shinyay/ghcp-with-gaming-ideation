Inference / traversal equivalence
OUT: (384×16)÷216 = 28.44 tick  =  (320×16)÷180 = 28.44 tick
RETURN: (384×16)÷288 = 21.33 tick  =  (320×16)÷240 = 21.33 tick

画面幅と速度がともに5/6へ縮み、単純な横断tick数は往路・帰路とも旧sheetと1998 projectionで一致する、と計算できる。公開cardの「およそ0.5秒」はoutbound 28.44 tick ÷ 60Hz ≒ 0.47秒と近い。
